These files are ready to use in the developer dashboard. They stay outside the extension ZIP.

## Images

| Asset | File | Dimensions |
| --- | --- | --- |
| Extension icon | [icon-128.png](../icons/icon-128.png) | 128 × 128; includes 16 px transparent padding |
| Switcher screenshot | [switcher.png](screenshots/switcher.png) | 1280 × 800 |
| Small promotional image | [promo-small.png](promo-small.png) | 440 × 280 |

The screenshot shows the actual extension with eight neutral sample tabs. All displayed domains end in `.example`; no personal browsing data was used. The promotional image uses the approved Eightfold icon. Both images were captured through Chrome DevTools MCP as 24-bit RGB PNGs, with no transparency or personal/device metadata. Their only ancillary PNG chunk is a color profile.

Google requires at least one screenshot and a small promotional image. See [image requirements](https://developer.chrome.com/docs/webstore/images).

## Account details before submission

Set the public publisher name and a suitable public contact email, verify the trader disclosure, and check the listing preview. Follow the [publishing guide](../docs/publishing.md). These assets do not configure, upload to, or publish through a Google account.
